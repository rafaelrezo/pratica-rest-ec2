IFES · Redes para Controle e Automação · 2026/2

Uma página. Duas práticas de redes.

Este portal é servido pelo Nginx em uma instância EC2 Ubuntu.

01 · HTTP e HTTPS

Inspecione a requisição do documento no DevTools. Compare status, cabeçalhos, endereço, porta e certificado. HTML, CSS e JavaScript são arquivos estáticos.

02 · Inventário de equipamentos

Use a API para cadastrar equipamentos fictícios. O campo “ativo” é apenas um dado do cadastro; ele não comanda nenhum equipamento.

Abrir interface do CRUD →

Antes da instalação do backend, as chamadas a /api podem retornar 502. Isso não impede a prática 1.

Laboratório didático isolado. Nenhum CLP ou processo real está conectado.
